Milo can now tell you when your agent needs you, let you edit the file you’re looking at, and explain which usage limit is running low. Start with `milo web` to explore the redesigned settings dashboard. It’s bundled with Milo and runs locally; you don’t need Node.js or a Milo account.

### Take Rex alerts with you

- In **Integrations → Alert forwarding**, connect a Discord channel, a Telegram private chat, or both. Choose which events matter: a blocked, failed or finished run, a notification, or a bell. Rex still shows its own alerts. Forwarding is off by default, and program text is a separate opt-in.
- **Connect with Milo** handles provider setup. Paste or autofill the finish code to see the destination, then explicitly save it. Test, enable or disconnect each destination independently. Replacing a credential pauses forwarding to that destination until you approve it again.
- Discord alerts go directly from your device to the approved webhook. The official Telegram bot delivers through Milo’s relay to the DM you confirmed. Prefer to manage your own credentials? Manual setup still works. [Setup guide](https://github.com/mcc0x/milo/blob/v0.1.5/docs/setup.md) · [#25](https://github.com/mcc0x/milo/pull/25), [#29–32](https://github.com/mcc0x/milo/pull/29)
- **Discord Rich Presence** is separate from forwarding. Show that you’re in Rex without publishing a project or session name. Each detail is opt-in; presence works through the local Discord desktop client. [#24](https://github.com/mcc0x/milo/pull/24)

### Edit where you read

Press `e` on an editable working file in Reader. Make a change, undo it, or use `Ctrl-F` to format with a supported tool you already have installed. Formatting changes the **draft**, not the file; only `Ctrl-S` writes it. A failed formatter leaves your draft intact. More languages get syntax highlighting, and working-file diffs refresh without losing the held project. [Reader guide](https://github.com/mcc0x/milo/blob/v0.1.5/docs/panes.md) · [#18](https://github.com/mcc0x/milo/pull/18)

### Know what your usage numbers mean

- The macOS menu explains which quota drives its badge. Low-quota notifications are optional. Missing readings, historical readings and exhausted quotas are distinct, so unavailable data doesn’t look like zero remaining. [#16](https://github.com/mcc0x/milo/pull/16)
- Opt into account readings for **DeepSeek, OpenRouter, Devin and GitHub Copilot**. Balances, spend and credits are shown in their own units, not turned into misleading percentages or low-quota alerts. These integrations use credentials you explicitly supply for Milo. [Usage guide](https://github.com/mcc0x/milo/blob/v0.1.5/docs/usage.md) · [#23](https://github.com/mcc0x/milo/pull/23)

### Find settings faster

The local dashboard now groups panes, usage and integrations in a sidebar. Pane controls follow the rail order; save, discard and recovery actions stay visible. Menu app installation and updates have their own controls, and Health shows a concise result. Milo Home distinguishes browser settings from terminal settings, and tells you where settings were saved and when a pane needs reopening. [#27](https://github.com/mcc0x/milo/pull/27)

### Fixes and reliability

- **Outline and History:** double-click compact Outline entries to open them. Changed-file jumps now explain why they can’t move. Expand commits with Right or `l`, see the short revision inline, and only see a truncation notice when older commits actually exist. Shallow Git history is distinguished from a Git error.
- **Rex tabs and worktrees:** restored sidebars are recognized before rebuilding. Panes name the project they’re holding while waiting for the shell, and distinguish a disconnected tracker from a pending report. Sibling-only Git changes no longer cause unnecessary refreshes; shared worktree changes are still noticed.
- **Responsiveness:** cancellation remains responsive when terminal output stalls. Startup avoids unnecessary speculative refreshes, and the menu resumes unfinished Claude usage reads without waiting through another idle interval.
- **Install and upgrade:** reinstall restores the managed executable; unsupported macOS versions are checked before replacement. Homebrew removal no longer depends on the candidate keg. Menu updates are distinct from removal, and menu-launched dashboard session keys stay out of Launch Services URLs.
- **Privacy and recovery:** pairing requires proof on both ends and expires. Stale confirmations cannot enable forwarding to a different recipient. Revoking one Telegram binding doesn’t disconnect other destinations; the relay won’t deliver on stale polling state. Saved configuration and menu launch paths receive additional validation.
- **Small screens:** Discord presence, alert forwarding and menu app controls wrap instead of clipping at narrow widths. A temporary relay outage no longer says the provider is disabled. [#36](https://github.com/mcc0x/milo/pull/36)
- **Source installs:** building the Cargo package from a checkout works even after installing the website and dashboard dependencies. [#35](https://github.com/mcc0x/milo/pull/35)
