# Milo v0.1.9 — Standalone Linux and Windows

Milo now runs standalone on Apple Silicon macOS, Linux x86-64 and native Windows x64. Open Home, browse a project and its Git history, edit a working file in Reader, and save settings in Milo’s local browser editor. Reader asks before replacing a file changed by another program.

## Install

- **Apple Silicon, macOS 13 or later:** download and run `sh install.sh`. This updates a previous script installation in place. The script checks the downloaded binary against its pinned SHA-256.
- **Linux x86-64, glibc 2.35 or later:** download `install-linux.sh` and `milo-x86_64-unknown-linux-gnu` into the same directory, verify their entries in `SHA256SUMS`, then run `sh install-linux.sh`. Run `~/.local/bin/milo` if that directory isn’t already on PATH.
- **Windows x64:** download `install-windows.ps1` and `milo-x86_64-pc-windows-msvc.exe` into the same directory, verify both against `SHA256SUMS`, and run the installer as your own user. Open a new terminal to pick up its PATH entry. The executable is unsigned, so Windows may warn about an unknown publisher. Use only the files from this release. If PowerShell refuses the verified script, run it in a single process with `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-windows.ps1`; this does not change system-wide policy.

The Linux and Windows installers verify the adjacent executable before placing it. They leave saved settings in place when upgraded or removed.

## Anonymous usage counts

These release binaries have counts on by default. The first eligible interactive launch sends nothing. A later launch can send one report per UTC day containing only the UTC date, whether this is the installation’s first report, and whether it’s the first report this calendar month. Milo doesn’t send an installation ID, project data, or agent usage. The receiving application stores aggregate totals; the hosting provider collects HTTP edge metadata separately, including source IP and request time. Counts are estimates, not a count of people.

Turn counts off in **Settings → Integrations → Anonymous usage counts**, or set `MILO_TELEMETRY=0` before launching Milo. The environment setting overrides a saved On preference, and a suppressed session doesn’t claim a reporting period. Source builds have no production receiver by default.

## Platform limits

- If the default browser can’t open the short-lived settings handoff file, open the private link Milo prints. This was needed with Firefox Snap on the tested Xubuntu desktop.
- Windows supports standalone workflows, not Rex, the macOS menu bar app, WebP preview or video playback. Milo’s Unix video preview needs supported FFmpeg/FFprobe and terminal output.
- Linux and Windows packages are for the named x64 targets. Linux musl, WSL, other architectures, and new Rex parity are not part of this release.
